# 🎓 EduCGPA

**EduCGPA** is a modern and responsive **GPA & CGPA Calculator** built using **HTML, CSS, and JavaScript**. It helps engineering and college students calculate their **semester GPA** and **overall CGPA** quickly and accurately using subject grades and credit points.

---

## 🌐 Live Demo

🔗 **Website:** https://educgpa.web.app

---

## ✨ Features

* 📘 **Semester GPA Calculator**
* 📗 **Overall CGPA Calculator**
* ➕ Add and remove subjects dynamically
* ➕ Add and remove semester GPA entries
* 📊 Credit-weighted GPA calculation
* 🎨 Modern colorful user interface
* 📱 Fully responsive design for mobile and desktop
* ⚡ Fast and lightweight (pure HTML, CSS & JavaScript)

---

## 📖 GPA Calculation Formula

```
GPA = Σ (Credit × Grade Point) / Σ Credits
```

Example:

| Subject     | Credit | Grade | Grade Point |
| ----------- | ------ | ----- | ----------- |
| Maths       | 4      | A+    | 9           |
| Physics     | 3      | A     | 8           |
| Programming | 3      | O     | 10          |

---

## 📖 CGPA Calculation Formula

```
CGPA = Σ Semester GPA / Number of Semesters
```
